# ni-doc Budget UI

Tela de criação e edição de orçamentos do **ni-doc**, construída com React, TypeScript, Vite e Microsoft Fluent UI 2.

## Executar localmente

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Recursos

- App shell responsivo com sidebar e header
- Tema claro e escuro
- Formulário de dados do orçamento
- Itens editáveis com cálculo automático
- Condições de pagamento e validação de percentuais
- Resumo financeiro e desconto global
- Feedback por toast e acessibilidade WCAG
